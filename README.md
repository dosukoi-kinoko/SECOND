# シロクマ天使のキューピッド大作戦 🐻💌

頭に輪っか・背中に羽のシロクマ天使（恋のキューピッド）が、依頼主から預かった
ラブレターを本命のお相手に届けるポップな片手ゲームです。

- **完全ゼロコスト**：画像ファイル0個 / 音源ファイル0個 / 外部ライブラリ0個。
  キャラも効果音もすべて Canvas2D と WebAudio でコード生成しています。
- **スマホもPCもOK**：タップ／クリック／スペースキーの **1操作だけ**。
- **単一ファイル**：`index.html` を開くだけで動きます。

## 遊び方

1. タップ（クリック / スペース）で **ふわっ** と浮く。
2. 空から降ってくる **トゲ** をよけ、**星** を拾ってスコアアップ。
3. てっぺんで3人のお相手と出会う。
4. それぞれの高さに合わせて **ねらう** と、左上の依頼主が反応する。
   **本命に合うとドキドキ💓** ＝ それが正解のヒント。
5. 本命にそろえたまま少し待つ（ためゲージが満ちる）と **ラブレター配達成功**。
   依頼主と本命の間に **運命の赤い糸** がハートを描きます。

ステージ1は **縦長画面・全5ミッション**。依頼主はネコの女の子、本命はゾウ。
ミッション3以降はお相手が **シルエット** になり、見た目で覚えられません。
依頼主の反応を読んで本物を見ぬきましょう。

## 公開（GitHub Pages）

このリポジトリの Settings → Pages で、ブランチを公開対象に設定すると
`https://<user>.github.io/<repo>/` で無料公開できます（ビルド不要）。

## ローカルで動かす

`index.html` をブラウザで開くだけ。サーバーは不要です。
（音はブラウザの仕様上、最初のタップで有効になります。）

## デバッグ

`window.__dbg` から `state` / `game` / `lvl` を参照でき、
`__dbg.forceJudge()` / `__dbg.forceWin()` で各フェーズを確認できます。
